## 先纠正参考方法

《通道观察》写的是：224输入得到LL112/56/28后补0至224，而不是双线性插值放大。
文档还记录原图与逐级加入LL的训练组合，但没有给出完整混合比例、补零位置、
归一化先后或训练预算。此前本地插值组及直接80输入组均不能当作这套方法的复现。
详见[METHOD_CORRECTION.md](METHOD_CORRECTION.md)。未上传用户提供的原始Word文档。

## 接下来的实验

1. 先核对LL补零位置、幅值与归一化顺序，做同图可视化及数值检查。
2. 在MCUNet原生160适配下，比较RGB-only、LL1-pad-only、RGB+LL1-pad混合三组；
   同数据、初始化、20轮上限和总更新预算，首轮不加额外颜色或遮挡增强。
3. 再决定是否加入LL2/LL3；需要实际加速时，另外比较小尺寸推理或真正区域跳算。

完整采样比例、主指标、预算、BN与阶段准入见[EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md)。
补零到160仍约67.2872M CNN MAC，零多不会让普通稠密卷积自动少算；
不能直接按有效像素面积宣称1/4成本。混合训练能否恢复精度需要实际结果。
